# ByteLab — Final Website

This is a deployment-ready static website for ByteLab.

Included:
- ByteLab logo
- Python Foundations course
- Google Meet live-class button
- Instagram timing/details notice
- Daily rotating coding challenge
- Project showcase
- Project/challenge submission form
- Local-browser demo statistics
- Student registration/enrollment form
- Responsive mobile layout

IMPORTANT:
The registration, submission and statistics forms are intentionally local-browser demos. They are NOT a real shared database and must not be presented as total platform statistics.

For a real launch, connect the forms to a backend/database or a Google Form/Sheet and add privacy/consent language appropriate for the students you serve.
